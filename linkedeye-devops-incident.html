💻 API Integration Code
Jenkins Pipeline Script (Groovy)
post { failure { script { def incident = [ short_description: "Deployment Failed - ${env.JOB_NAME} #${env.BUILD_NUMBER}", description: "Pipeline: ${env.JOB_NAME}\nBuild: #${env.BUILD_NUMBER}\nStatus: FAILED\n\nError: ${currentBuild.result}", priority: "Critical", category: "DevOps/Deployment", assigned_group: "DevOps Team" ] httpRequest( url: "https://linkedeye-finspot.com/api/incidents", httpMode: 'POST', contentType: 'APPLICATION_JSON', authentication: 'jenkins-api-token', requestBody: groovy.json.JsonOutput.toJson(incident) ) } } }
GitHub Actions Workflow (YAML)
- name: Create Incident on Failure if: failure() uses: linkedeye-finspot/create-incident@v1 with: api-key: ${{ secrets.LINKEDEYE_API_KEY }} short-description: 'Deployment Failed - ${{ github.workflow }}' priority: 'Critical' category: 'DevOps/Deployment' description: | Workflow: ${{ github.workflow }} Run: ${{ github.run_number }} Commit: ${{ github.sha }} Error: Deployment to production failed
cURL Command
curl -X POST https://linkedeye-finspot.com/api/incidents \ -H "Authorization: Bearer YOUR_API_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "short_description": "Production Deployment Failed", "description": "Detailed error information...", "priority": "Critical", "category": "DevOps/Deployment", "assignment_group": "DevOps Team" }'
