Prometheus Configuration

Configure Prometheus to send alerts to LinkedEye-FinSpot incident management system

prometheus-rules.yml
groups: - name: linkedeye_incidents interval: 30s rules: - alert: HighPodCPUUsage expr: | (sum(rate(container_cpu_usage_seconds_total[5m])) by (pod) / sum(container_spec_cpu_quota) by (pod)) > 0.9 for: 5m labels: severity: critical category: Infrastructure annotations: summary: "High CPU usage on {{ $labels.pod }}" description: "Pod {{ $labels.pod }} CPU > 90%" incident_priority: "Critical" incident_category: "Infrastructure"
Webhook Integration
# Add to alertmanager.yml receivers: - name: linkedeye-finspot webhook_configs: - url: 'https://linkedeye-finspot.com/api/alerts/prometheus' send_resolved: true http_config: bearer_token: 'YOUR_API_TOKEN'

Alertmanager Configuration

Route alerts from Alertmanager to create incidents automatically

alertmanager.yml
global: resolve_timeout: 5m route: group_by: ['alertname', 'cluster', 'service'] group_wait: 10s group_interval: 10s repeat_interval: 12h receiver: 'linkedeye-finspot' routes: - match: severity: critical receiver: linkedeye-critical continue: true receivers: - name: 'linkedeye-finspot' webhook_configs: - url: 'https://linkedeye-finspot.com/api/alerts' send_resolved: true - name: 'linkedeye-critical' webhook_configs: - url: 'https://linkedeye-finspot.com/api/alerts/critical' send_resolved: true
