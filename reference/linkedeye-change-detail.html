PgBouncer Configuration Update - Increase Pool Size

Dec 26, 2025 18:00 IST Duration: 30 minutes fs-mum-indmoney-prod-le
Change Details

Description

Increase PgBouncer connection pool size from 256 to 384 connections to handle increased trading volume during peak hours. This change addresses recurring connection exhaustion incidents (INC0015847, INC0015721).

Business Justification

Trading operations have increased 40% over the past quarter. Current pool configuration is causing 3-5 connection exhaustion incidents per week during market open and close, impacting order processing SLAs.

Rollback Plan
Emergency Rollback Procedure
  1. Restore pgbouncer.ini from backup: cp /etc/pgbouncer/pgbouncer.ini.bak /etc/pgbouncer/pgbouncer.ini
  2. Reload PgBouncer: pgbouncer -R
  3. Verify rollback: SHOW POOLS; - confirm 256 max connections
  4. Notify stakeholders via Slack #incidents channel
  5. Create incident ticket for root cause analysis
