Root Cause Analysis

Identified Root Cause

Problem: Connection leak in trading-api v2.4.3 causing progressive exhaustion of PostgreSQL connection pool during high-volume trading periods.

Contributing Factors:
  • No connection timeout configured in HikariCP pool settings
  • Insufficient connection pool monitoring and alerting thresholds
  • Connection pool size (256) inadequate for peak trading load
  • Missing connection validation on checkout from pool
  • Retry logic not releasing connections on certain error paths
