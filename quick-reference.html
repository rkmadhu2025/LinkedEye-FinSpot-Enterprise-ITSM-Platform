🔧 Common Troubleshooting Commands

iLO Exporter Issues

# Check iLO connectivity curl -k https://192.168.1.10/redfish/v1/ # Test exporter endpoint curl http://ilo-exporter:9416/metrics # Check Prometheus target kubectl port-forward svc/prometheus 9090:9090 # Visit: http://localhost:9090/targets # View exporter logs kubectl logs -n monitoring deployment/ilo-exporter -f

SNMP Exporter Testing

# Test SNMP walk snmpwalk -v2c -c linkedeye_readonly 192.168.1.1 1.3.6.1.2.1.1 # Test exporter curl 'http://snmp-exporter:9116/snmp?target=192.168.1.1&module=cisco_switch' # Generate custom SNMP config docker run --rm -v "${PWD}:/opt" prom/snmp-generator generate

Keycloak Operations

# Access Keycloak CLI kubectl exec -it deployment/keycloak -n auth -- bash cd /opt/keycloak/bin ./kcadm.sh config credentials --server http://localhost:8080 \ --realm master --user admin # List realms ./kcadm.sh get realms # Export realm configuration ./kcadm.sh get realms/linkedeye > linkedeye-realm.json # Create new client ./kcadm.sh create clients -r linkedeye -f client.json

Prometheus Queries

# Check target up status up{job="ilo-exporter"} # iLO temperature metrics ilo_temperature_celsius{sensor=~".*CPU.*"} # Network interface bandwidth rate(ifHCInOctets[5m]) * 8 # Alert rules status ALERTS{alertstate="firing"} # Scrape duration scrape_duration_seconds{job="snmp-exporter"}

Jenkins Pipeline Debugging

# Check Jenkins logs kubectl logs -n cicd deployment/jenkins -f # Get pipeline console output kubectl exec -it deployment/jenkins -n cicd -- \ cat /var/jenkins_home/jobs/linkedeye-backend/builds/lastBuild/log # Test Keycloak connection curl -X POST https://keycloak.linkedeye.local/realms/linkedeye/protocol/openid-connect/token \ -d "client_id=jenkins-client" \ -d "client_secret=YOUR_SECRET" \ -d "grant_type=client_credentials"

ArgoCD Operations

# Login to ArgoCD argocd login argocd.linkedeye.local --sso # List applications argocd app list # Sync application argocd app sync le-backend --prune # Get application details argocd app get le-backend # View sync status argocd app wait le-backend --health # Rollback argocd app rollback le-backend

🎯 Emergency Procedures

iLO Temperature Alert

1. Check current temperature: kubectl logs deployment/ilo-exporter | grep temp 2. Identify affected server from alert labels 3. Verify cooling system via iLO web UI 4. If temp > 90°C: Initiate workload migration 5. Contact datacenter for physical inspection 6. Document in incident tracker

Network Interface Down

1. Identify interface from AlertManager 2. Check physical connectivity 3. Verify SNMP data: snmpget -v2c -c linkedeye_readonly IP IF-MIB::ifOperStatus.X 4. Check switch logs for errors 5. Failover to redundant link if available 6. Create change ticket for physical repair

Trading Platform Outage

1. IMMEDIATE: Notify trading desk 2. Check Blackbox probe results 3. Verify backend services: kubectl get pods -n trading 4. Check database connectivity 5. Review recent deployments in ArgoCD 6. Rollback if deployment-related 7. Execute disaster recovery if hardware failure 8. Document timeline for post-mortem
