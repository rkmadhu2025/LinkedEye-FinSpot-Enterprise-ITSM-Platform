📊 Webhook Receivers Overview

🌐 Network Device Receivers (7 receivers)

1. snmpwebhook

Cisco Switches

Target: Generic SNMP-enabled switches

Alert Types:

  • Interface down/up
  • High CRC errors
  • Bandwidth saturation
  • VLAN configuration issues
  • STP topology changes

Label Matcher: device_type="switch", vendor="cisco"

2. fortigatewebhook

Firewalls

Target: FortiGate firewall appliances

Alert Types:

  • Session table exhaustion
  • VPN tunnel down
  • Threat detection
  • High CPU/memory usage
  • IPS signature updates

Label Matcher: device_type="firewall", vendor="fortinet"

3. routerwebhook

Routers

Target: Cisco/Juniper routers

Alert Types:

  • BGP peer down
  • OSPF neighbor loss
  • High packet loss
  • Routing table full
  • QoS policy violations

Label Matcher: device_type="router"

📋 Label Standards for Alerts

Required Labels for Proper Routing

Label Name Purpose Example Values
device_type Type of device generating alert switch, router, firewall, server, vm
vendor Device manufacturer cisco, dell, hpe, fortinet, huawei, aruba, arista
severity Alert severity level critical, warning, info
job Prometheus job name snmp-exporter, blackbox-exporter, ilo-exporter
monitor_type Monitoring method ipmi, snmp, redfish, wmi
os Operating system windows, linux, esxi
alert_type Category of alert hardware, network, performance, security
